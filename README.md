# 批量与多人物矩阵转换插件 (`memestudio.batch-convert`)

本插件作为独立的任务队列与笛卡尔积矩阵工作流，提供以下三种批量模式：

1. **多原图 × 单人物 ($X \times 1 \rightarrow X$)**：将整套表情包目录批量替换为同一目标角色。
2. **单原图 × 多人物 ($1 \times Y \rightarrow Y$)**：固定 1 张经典表情模板，一键为 $Y$ 名不同角色各自生成对应表情。
3. **多原图 × 多人物 ($X \times Y \rightarrow X \cdot Y$)**：输入 $X$ 张源表情与 $Y$ 张人物参考图（支持多选图片或直接导入文件夹），自动生成全部 $X \times Y$ 组组合（可选按人物名分建子目录保存）。

## 核心特性

- **文件头极速探测**：通过 `host->probe_media` 仅读取头部宽高与帧数（跳过非图像或损坏文件并自动去重），导入百张素材零界面卡顿。
- **防覆盖与重名消歧**：预计算全部源图、人物图与附加画风参考的规范路径哈希，杜绝覆盖任何输入文件，并对跨目录同名素材自动追加短哈希后缀。
- **单条故障隔离**：启用 `continue_on_error` 时，任意单个 `(源图, 人物)` 组合生成异常均独立记录于结果表，不中断其余组合继续产出。
- **多前端就绪 (`get-ui-schema`)**：内置声明式表单 Schema，供未来 WinUI 3 / WebView2 前端自动渲染原生 Fluent 界面。
